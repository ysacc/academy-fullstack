# Semana 11 — Docker, CI/CD y deploy introductorio

## Objetivo
Empaquetar la aplicación y comprender un pipeline básico de entrega.

## Requisitos
- Dockerfile funcional para al menos un servicio.
- `.dockerignore`.
- Variables de entorno fuera de la imagen.
- Documentar build/run.
- Explicar etapas de CI/CD aunque la validación académica siga siendo local.
- Deploy de prueba del stack o de sus componentes.

## Challenge
Usa Docker Compose para app + DB.

## Test local
`npm run test:week11`

## Entrega
Repo + enlace al entorno cuando corresponda.
