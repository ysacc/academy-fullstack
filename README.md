# Academy Full Stack

Programa práctico de 16 semanas · 64 horas en vivo · 2 clases por semana · 2 horas por sesión.

Ruta orientada a construir aplicaciones Full Stack con React, Node.js/NestJS, PostgreSQL, autenticación, testing, Docker, CI/CD introductorio y trabajo colaborativo con Git/GitHub.

## Metodología

Este repositorio público contiene el material del alumno. Cada semana incluye:

- `README.md`: objetivos, homework, requisitos y entrega.
- `starter/`: punto de partida incompleto.
- tests locales: validan requisitos mínimos antes de subir el trabajo.

El material docente, guiones de clase, bugs intencionales, criterios internos de Code Review y referencias se mantienen en un repositorio privado del instructor.

Los tests **no se ejecutan en GitHub Actions**. El alumno los corre localmente y, cuando pasan, sube su trabajo a su propio repositorio y comparte el enlace.

## Ecosistema Academy

Ruta recomendada:

1. [Desde Cero](https://github.com/ysacc/academy-desde-cero) — fundamentos web.
2. [Frontend React](https://github.com/ysacc/academy-frontend-react) — frontend profesional.
3. **Full Stack** — backend, bases de datos, integración, arquitectura y trabajo colaborativo.

Programas complementarios:

- [Preparación para Entrevistas](https://github.com/ysacc/academy-entrevistas).
- [Mentoría](https://github.com/ysacc/academy-mentoria).

### Requisito recomendado

Llegar dominando los fundamentos de React, TypeScript, Git, APIs y testing frontend, o demostrar un nivel equivalente.

### Siguiente paso recomendado

Al completar el proyecto grupal, usar **Preparación para Entrevistas** para convertir la experiencia técnica en desempeño de selección, o **Mentoría** para definir un roadmap profesional personalizado.
