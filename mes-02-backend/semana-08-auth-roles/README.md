# Semana 8 — Autenticación, autorización y roles

## Objetivo
Implementar un flujo de autenticación básico y proteger recursos por permisos.

## Requisitos
- Registro/login o flujo equivalente.
- Password hash, nunca texto plano.
- Token o sesión.
- Endpoint protegido.
- Diferencia entre 401 y 403.
- Al menos 2 roles o permisos.
- Secretos mediante variables de entorno.

## Challenge
Agrega refresh token o revocación simple.
