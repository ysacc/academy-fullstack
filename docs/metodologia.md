# Metodología — Academy Full Stack

## Estructura

- 16 semanas.
- 64 horas en vivo.
- 2 clases por semana.
- 120 minutos por clase.
- 4 horas semanales en vivo.

## Clase A — Fundamentos + práctica guiada

- 0–15 min: repaso, bloqueos y preguntas.
- 15–40 min: concepto principal.
- 40–70 min: live coding.
- 70–100 min: ejercicio guiado.
- 100–115 min: debugging y variaciones.
- 115–120 min: checkpoint.

## Clase B — Aplicación + pairing + review

- 0–15 min: revisión del checkpoint.
- 15–35 min: ampliación técnica.
- 35–65 min: desarrollo aplicado.
- 65–95 min: code pairing.
- 95–110 min: tests locales y Code Review.
- 110–120 min: homework y cierre.

## Flujo profesional

A partir de las primeras semanas se refuerza:

`Ticket → Branch → Desarrollo → Tests locales → Commit → Push → PR → Review`

En el proyecto grupal se agregan Backlog, Sprint Planning, Daily, Refinement, Review y Retrospective.

## IA

Puede utilizarse para investigar, depurar, generar tests, documentar y refactorizar. El alumno debe poder explicar, modificar y defender todo código asistido por IA.
