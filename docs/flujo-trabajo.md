# Flujo de trabajo

## Individual

1. Leer el ticket o tarea.
2. Crear branch descriptiva.
3. Implementar en pasos pequeños.
4. Ejecutar tests locales.
5. Revisar consola, logs y errores.
6. Crear commits descriptivos.
7. Push al repositorio propio.
8. Abrir PR cuando la actividad lo requiera.
9. Aplicar observaciones de Code Review.

## Proyecto grupal

- Backlog compartido.
- Sprint Planning.
- Daily breve.
- Refinement.
- PR obligatorio por feature.
- Review entre compañeros.
- Sprint Review.
- Retrospective.

El objetivo es practicar hábitos de un equipo real, no simular ceremonias sin propósito.
