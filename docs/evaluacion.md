# Evaluación

Los tests locales validan requisitos objetivos, pero no reemplazan la revisión humana.

## Se evalúa

- funcionamiento;
- calidad y legibilidad;
- separación de responsabilidades;
- manejo de errores;
- diseño de API y datos;
- seguridad básica;
- testing;
- Git y calidad de commits;
- capacidad de explicar decisiones;
- aplicación del feedback de Code Review;
- trabajo colaborativo en el proyecto grupal.

## Entrega

1. Ejecutar los tests de la semana en local.
2. Corregir hasta que pasen.
3. Subir el trabajo al repositorio personal o grupal indicado.
4. Compartir el enlace con el instructor.

No hay validación automática mediante GitHub Actions en este repositorio académico.
