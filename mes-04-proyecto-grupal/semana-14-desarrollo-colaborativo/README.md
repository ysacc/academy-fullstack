# Semana 14 — Proyecto grupal: desarrollo colaborativo

## Objetivo
Entregar features mediante branches, PRs y colaboración real.

## Requisitos
- Trabajo desde tickets.
- Branch por feature/fix.
- Commits comprensibles.
- PR con contexto y cómo probar.
- Al menos un review de compañero.
- Integración frecuente.
- Daily breve enfocada en avance/bloqueos.

## Entrega
Repo grupal con PRs y avance funcional.
