# Semana 3 — Routing, APIs y manejo de datos

## Objetivo
Construir una SPA con navegación y consumo robusto de API.

## Requisitos
- Al menos 3 rutas.
- Ruta con parámetro.
- Capa o función de acceso a API.
- Loading, error y empty state.
- Cancelación o prevención de actualización obsoleta cuando aplique.
- UI separada de acceso a datos.
