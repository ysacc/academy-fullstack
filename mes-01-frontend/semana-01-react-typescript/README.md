# Semana 1 — React + TypeScript aplicado

## Objetivo
Reforzar React con TypeScript y trabajar componentes con contratos claros.

## Homework
Construye una vista de catálogo tipada con componentes reutilizables.

## Requisitos
- React + TypeScript.
- Tipos o interfaces para datos y props.
- Al menos 3 componentes.
- Props tipadas.
- Render de colección con `key` estable.
- Estado local para una interacción.
- Sin `any` como solución principal.

## Challenge
Agrega estados derivados sin duplicar información en state.

## Test local
