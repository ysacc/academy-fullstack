# Semana 2 — Estado, formularios y componentes

## Objetivo
Diseñar formularios controlados y manejar estado sin mezclar responsabilidades.

## Homework
Construye un formulario de alta/edición de una entidad.

## Requisitos
- Inputs controlados.
- Validación mínima.
- Mensajes de error visibles.
- Estado de submit.
- Separar formulario y presentación.
- Evitar mutación directa del state.

## Challenge
Extrae lógica reutilizable a un custom hook.
